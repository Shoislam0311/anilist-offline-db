Available Types

Page - Paginated results .media(type: MediaType, sort: [MediaSort], page: Int, perPage: Int): [Media] .pageInfo: PageInfo Media - Anime entry .id, .idMal, .title (MediaTitle), .description, .coverImage (CoverImage) .bannerImage, .episodes, .duration, .status, .format, .season, .seasonYear .averageScore, .meanScore, .popularity, .favourites, .trending .genres: [String], .tags: [MediaTag] .studios: StudioConnection .characters: CharacterConnection .relations: MediaConnection .recommendations: RecommendationConnection .nextAiringEpisode: AiringSchedule .startDate, .endDate: FuzzyDate .externalLinks: [MediaExternalLink] .streamingEpisodes: [MediaStreamingEpisode] MediaSort: ID, POPULARITY_DESC, SCORE_DESC, UPDATED_AT_DESC, START_DATE_DESC, FAVOURITES_DESC, TRENDING_DESC MediaType: ANIME, MANGA MediaStatus: FINISHED, RELEASING, NOT_YET_RELEASED, CANCELLED, HIATUS MediaFormat: TV, MOVIE, OVA, ONA, SPECIAL, MUSIC, MANGA, NOVEL, ONE_SHOT, OEL, MANHWA, MANHUA

Example Queries

# Get top anime by popularity { Page(page: 1, perPage: 10) { media(sort: POPULARITY_DESC, type: ANIME) { id title { romaji english } averageScore } } } # Search by title { Page(page: 1, perPage: 5) { media(search: "naruto", type: ANIME) { id title { romaji } episodes } } } # Filter by genre and year { Page(page: 1, perPage: 10) { media(genre: "Action", seasonYear: 2024, type: ANIME) { id title { romaji } format } } }
